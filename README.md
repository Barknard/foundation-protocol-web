# Mother Sauce

One-button weekly meal engine for a family of five. Front-load the flavor into one Sunday prep block, coast the weeknights. Vanilla JS, single file, no build step.

## Deploy

1. Push this repo to GitHub (public is fine, there are no secrets in it).
2. Repo Settings, Pages, Source: Deploy from a branch, Branch: main, folder: / (root), Save.
3. Wait a minute, then open `https://<owner>.github.io/mother-sauce/`.

## Install on a phone

Open the URL in Chrome on Android, browser menu, Add to Home screen, install.

## First run

The app asks for an Anthropic API key from console.anthropic.com. The key is stored only in localStorage on your device and sent only to api.anthropic.com. A generated week costs about a cent.

## Offline

A service worker caches the app shell, so the last generated plan and list open offline. Generating or swapping needs a connection.

## Icons

`icon-192.png` and `icon-512.png` are generated by `make_icons.py` (needs Pillow: `pip install pillow`).

## APK later

These files drop unchanged into a Capacitor webDir if a real signed APK is ever wanted.
